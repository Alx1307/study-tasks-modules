### Мини веб служба и конвейер обработки запросов (Модульная архитектура)

Модульная REST API система для управления учебными задачами с поддержкой аутентификации, отчетности и конвейерной обработки запросов.

Использованный стек технологий: Node.js, Express, JWT, bcrypt, UUID.

## Архитектура проекта

Проект построен на **модульной архитектуре**, где ядро приложения ничего не знает о деталях модулей, а только подчиняется контракту. Каждый модуль:

- Имеет уникальное имя
- Определяет список зависимых модулей
- Регистрирует свои сервисы через DI контейнер
- Настраивает собственные маршруты
- Выполняет инициализацию

## Конвейер обработки запросов

Каждый HTTP запрос проходит через последовательность независимых обработчиков (middleware):

1. **RequestIdMiddleware** — добавляет уникальный идентификатор к каждому запросу
2. **RequestLoggerMiddleware** — измеряет время выполнения и логирует успешные запросы
3. **Маршрутизация** — обработка запроса соответствующим модулем
4. **ErrorHandlerMiddleware** — перехватывает исключения и формирует единый формат ошибок

## Порядок запуска приложения

При запуске приложения выполняется следующая последовательность действий:

ЗАПУСК ПРИЛОЖЕНИЯ (npm start)

↓

ЧТЕНИЕ КОНФИГУРАЦИИ (config/modules.json)

↓

ЗАГРУЗКА МОДУЛЕЙ ИЗ ПАПКИ modules/

↓

ПРОВЕРКА НАЛИЧИЯ ЗАВИСИМОСТЕЙ (все требуемые модули загружены, обнаружение циклических зависимостей)

↓

ПОСТРОЕНИЕ ПОРЯДКА ЗАГРУЗКИ (Core → Auth → Tasks → Reports)

↓

СОЗДАНИЕ DI КОНТЕЙНЕРА (new Container())

↓

НАСТРОЙКА КОНВЕЙЕРА (middleware)

↓

РЕГИСТРАЦИЯ СЕРВИСОВ (module.register) - Core: clock, storage, Auth: auth, authMiddleware, Tasks: расширение storage методами, Reports: расширение storage методами

↓

НАСТРОЙКА МАРШРУТОВ (module.setupRoutes)

↓

ИНИЦИАЛИЗАЦИЯ МОДУЛЕЙ (module.init)

↓

НАСТРОЙКА ОБРАБОТЧИКА ОШИБОК (errorHandlerMiddleware)

↓

ЗАПУСК СЕРВЕРА (app.listen)

↓

ОЖИДАНИЕ HTTP ЗАПРОСОВ

## Установка и запуск

1. Клонировать репозиторий:
```
git clone https://github.com/Alx1307/study-tasks-modules.git
cd study-tasks-modules
```
2. Установить зависимости:
```
npm install
```
3. Запустить сервер:
```
npm start
```
4. Запустить тесты:
```
npm run test:auth
npm run test:tasks
npm run test:reports
npm run test:deps
```

Сервер запустится на http://localhost:3000

## API Endpoints

### Модуль Core (базовый)

GET	/health	- Проверка работоспособности сервера

### Модуль Auth (аутентификация)

POST	/auth/register	- Регистрация нового пользователя

POST	/auth/login	- Вход в систему (получение JWT токена)

GET	/auth/me	- Получение информации о текущем пользователе

POST	/auth/refresh	- Обновление JWT токена

POST	/auth/logout	- Выход из системы

### Модуль Tasks (управление задачами)

POST	/create-tasks	- Создание новой задачи

GET	/tasks	- Получение всех задач текущего пользователя

GET	/tasks/:id	- Получение задачи по ID

PUT	/tasks/:id	- Полное обновление задачи

PATCH	/tasks/:id/status	- Обновление статуса задачи

DELETE	/tasks/:id	- Удаление задачи

### Модуль Reports (отчеты и статистика)

GET	/reports/stats	- Общая статистика по задачам

GET	/reports/overdue	- Просроченные задачи

GET	/reports/completion-timeline	- Таймлайн завершенных задач

GET	/reports/productivity	- Оценка продуктивности

GET	/reports/tasks-by-period?days=7	- Задачи за выбранный период
